# Website

Статический сайт на HTML/CSS/JS, верстаем по макетам из Figma.
Живёт в папке `website/` ветки `website` форка markitdown.

## Структура
- `index.html` — страницы в корне
- `css/style.css` — стили; цвета и шрифты держим в переменных `:root`
- `js/main.js` — скрипты
- `assets/` — то, что идёт на сайт: `images/`, `icons/`, `fonts/`
- `design/` — исходники из Figma: `screens/` (скриншоты макетов), `exports/` (экспорт до оптимизации)
- `docs/progress.md` — что сделано и что дальше

## Правила
- Без фреймворков и сборщиков, чистый HTML/CSS/JS.
- Сначала мобильная версия, потом десктоп.
- Картинки для сайта: WebP/SVG, до ~300 КБ.
- В конце каждой сессии обновлять `docs/progress.md`.

## Работа с двух компов (ПК + Mac)
- Перед началом: `git pull`. После: commit + push.
- Если работаем параллельно — разные ветки и Pull Request.
